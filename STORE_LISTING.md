# Store listing (Chrome Web Store / Edge Add-ons / Firefox AMO)
**Name:** PhoText - Edit Text in Image & Find Font
**Category:** Productivity (Chrome/Edge) · Photos/Appearance (Firefox)
**Short description (132 chars max):** Right-click any image to edit, remove or translate its text, or find its font, with PhoText at photext.ai.
**Detailed description:**
PhoText (https://photext.ai) is an AI tool that edits text inside images while keeping the original font style.
This extension adds four right-click options to any image:
• Edit text with PhoText: change words in photos, screenshots, posters and product images
• Remove text with PhoText: erase captions or text and restore the background
• Translate image text with PhoText: translate the text in an image and keep the layout
• Find font with PhoText: identify the font used in an image
There is no sign-up inside the extension, and it collects no data or tracking.
